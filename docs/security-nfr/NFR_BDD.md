## Сценарий 1: Быстрый ответ API
**Given** пользователь открыл приложение
**When** он запрашивает список предложений
**Then** ответ должен прийти быстрее 500 мс

## Сценарий 2: Защита от перегрузки
**Given** пользователь создал 10 предложений за минуту
**When** он пытается создать 11-е предложение
**Then** система должна заблокировать запрос

## Сценарий 3: Валидация данных
**Given** форма создания предложения
**When** пользователь вводит заголовок длиннее 100 символов
**Then** система должна показать ошибку

## Сценарий 4: Доступность сервиса
**Given** сервис работает
**When** происходит сбой базы данных
**Then** сервис должен показать понятную ошибку

## Сценарий 5: Безопасность данных
**Given** пользователь заходит на сайт
**When** он отправляет данные
**Then** соединение должно быть по HTTPS
