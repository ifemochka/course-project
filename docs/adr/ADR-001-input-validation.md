# ADR-001: Валидация входных данных
Дата: 2025-10-22
Статус: Accepted

## Context
Пользователи отправляют предложения через REST API. Необходимо защититься от:
- Слишком длинных текстов 
- Невалидных данных
- Вредоносного контента

## Decision
Внедрить строгую валидацию на уровне API:
- Максимальная длина title: 200 символов
- Максимальная длина text: 5000 символов  
- Обязательная проверка user_id
- Запрет специальных символов в user_id

## Consequences
### Positive
- Защита от переполнения буфера
- Предотвращение SQL injection
- Улучшение качества данных

### Negative  
- Дополнительная нагрузка на CPU
- Возможные false-positive
